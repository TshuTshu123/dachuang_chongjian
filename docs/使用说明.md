## 日常运行

正常使用自己的账号和环境即可，不需要以管理员身份启动 VS Code。此前“助手生成的模型打不开、删除需管理员”是私有临时目录权限被带到最终文件的发布缺陷，现已修复；相关排查见 [试验过程](试验过程.md)。

在 VS Code 打开项目，激活自己的 Python 环境后：

```powershell
python run.py
```

默认处理 data 中最后修改的 PLY，以复现 history 的稳定 scan 参数重建，再自动进行法线与黑点处理、Meta/Sapiens 人体部位识别、面部/身体表面整理和统一手部质量检查。手部参数根据当前点云估计，正常区域跳过，异常区域仅采用通过检查的调整。最终生成一组 PLY、OBJ 和与最终模型匹配的 body_parts.json。指定编号更明确：

默认先拟合左右 MANO 候选，再成对判断是否替换。原掌厚 P85 需超过腕厚 25% 且多出至少 8 mm，同时候选在同一批有效掌部截面上至少减少 8 mm，才视为值得修复的明显差异。任一侧满足时尝试双手一起替换；两侧连接都通过才采用，否则保留双手，不再只换一只。正常手部、缺少可靠厚度参考、只有候选差异而没有原手过厚证据时保留原样；不按输入编号判断。启用 MANO 后，只重建腕口往手掌约 35 mm 的连接段，不再截换前臂段。模型在 `tools/mano/`，不需要安装旧 chumpy。模板补出的手指姿态不一定真实；无可靠人体/手部标签、缺少模型或检查失败时回退。判断记录在 report.json 的 mano_hand_processing.thickness_policy；候选、参数与对比图在本次输出的 `intermediate/mano/`，候选图不等于最终采用结果。顶点数量会变化，`body_parts.json` 已重新映射到最终网格；新增手部标签属于模板分配，不是重新识别的置信度。

腕部连接沿两端真实轮廓采样，结合保留侧表面的切向生成渐变曲面，减少椭圆截面硬接产生的环状台阶。仅重建掌侧连接段，原有前臂凸起、黑斑不在此步骤中去除；连接检查通过也不等于外观完全自然。

2026-11-13 起，版本 25 默认继续执行三项检查后整理，无需运行实验脚本：

1. MANO 替换通过后，局部细分掌面，仅融合距离参考面 3 mm 内、有邻域支持的原始观测小尺度变化，位移上限在 0.5/1 mm 中筛选。腕口与远端手指固定，检查掌厚、留出观测贴合、翻面和新增局部相交。
2. 以原扫描重建的腕部截面校正 MANO 衔接，按统一规则筛选 6/10/14 mm 位移上限；仅调整近腕约 -5 至 +40 mm 的过渡带，其他区域不动。只采用保留面连接的安全变形，不启用实验中的切除重接回退。失败的一侧保留该步输入。人工测量标记点不由程序推断。
3. 对躯干、上衣及衣袖作局部二次曲面去噪，比较 12 mm 邻域/1.5 mm 位移上限和 20 mm 邻域/3 mm 位移上限，选择起伏改善且通过复核的一档。已识别的其他部位固定，边界渐变；七个诊断截面的宽、厚变化上限各为 3 mm，周长变化上限为 2%。这些筛选门槛不是实际人体测量精度标准，衣服大褶皱和深凹坑可能保留。

三步分别写入 `report.json` 的 `mano_surface_refinement`、`wrist_alignment`、`torso_surface_refinement`。没有采用 MANO 时，跳过前两步；正常人体仍可单独尝试躯干去噪。非人体、部位信息不足或检查失败时保留该步输入并记录原因。PLY、OBJ、`body_parts.json` 同步发布，细分新增的掌部顶点继承手部标签，坐标、包围盒和哈希同步更新；中心线仅更新最终模型关联，不当作重新估计的关节或人工标记点。缓存包含这些步骤的代码，重复运行不会叠加修改。局部质量检查及外观改善不能证明测量准确率提高。

```powershell
python run.py 3
```

其他可选参数：

- `--all`：处理所有输入，已完成且校验一致的结果复用。
- `--redo`：强制重新生成，另建时间目录，不覆盖旧模型。
- `--fast`：粗采样和深度 8 的快速预览，跳过照片贴图。
- `--no-face-uv`：只跳过脸颈贴图导出，保留 RAW 顶点补色。
- `--unit m`：输入坐标单位为米，默认毫米，输出始终毫米。
- `--sole-axis x`：明确竖直方向为 X，也可写 y 或 z。
- `--up-sign -1`：竖直轴负向朝上，默认正向。
- `--sole-axis off`：关闭鞋底约束（现在为默认值）。
- `--refine`：显式开启额外双边网格过滤，默认不额外过滤。
- `--no-shoe-repair`：关闭鞋底截断补面；目前新数据也默认尝试处理，通常不用写。
- `--normals-only`：最终外观处理只修法线朝向，保留原始顶点颜色。
- `--no-appearance`：关闭最终法线和黑点处理，便于与原流程对比。
- `--no-segmentation`：同时跳过人体分割位置文件和手部局部平滑。
- `--no-hand-refine`：关闭默认的统一自动手部处理及 MANO 替换，仅保留部位位置文件。
- `--no-surface-refine`：关闭身体/面部轻度整理及躯干二次曲面去噪，手部处理仍由手部开关控制。
- `--hand-refine`：显式试用已撤回的掌面限厚和平滑；日常不需要使用。
- `--hand-skeleton`：试用稳定中心线限定的手指表面贴合，例如 `python run.py 3 --hand-skeleton`。与旧 `--hand-refine` 互斥，默认关闭；中心线不足或几何检查失败时保留原形。只轻度调整有观测支持的手指中段，不切开粘连指缝。
- `--hand-density`：在骨架贴合基础上，试验自适应密度虚接过滤与手部观测厚度约束，例如 `python run.py 3 --hand-density`。与其他手部开关互斥，默认关闭。可能留下开口，目前不是完整手指重建方案，效果见试验过程第三十二节。
- `--seg-python 路径`：指定已安装 GPU PyTorch 的 Python，当前默认使用本机 test0；也可设置 HUMAN_SEG_PYTHON 环境变量。
- `--seg-axis x`：指定人体分割的竖直轴，也可 y/z；默认 auto 最长轴，方向使用 `--up-sign`。

鞋底修复现已默认开放给新数据测试：将新 PLY 放入 data 后运行 `python run.py` 即可，也可写编号。已确认的 0001 仍用原配置；其他数据根据过滤后主体的包围范围估计底面，在观测最低处下方预留 3 mm，再尝试截断和补闭切口。新数据结果尚未逐份人工验收，不保证适合所有姿态。手部使用统一自动质量策略，是否处理由当前观测和检查结果决定。

自动模式以明显最长的坐标轴为竖直轴，并假设正向朝上。坐姿、横放、倒置、抬脚或背景未清理干净的数据不能直接信任该判断。可用 `--shoe-axis x`（也可 y/z）指定方向，负向朝上再加 `--up-sign -1`。想关闭则加 `--no-shoe-repair`。不要与旧的 `--sole-axis` 删面功能混用。

方向不明确、不需要裁切、拟删除顶点超过 8%、切口无法安全补面，或拓扑检查变差时，自动跳过鞋底处理并保留基础模型；控制台输出 WARNING，report.json 中 shoe_repair.enabled 为 false 并写明原因。看到模型导出成功，不等于鞋底一定处理成功。切口上方几何不移动，但新底面仍为近似平面，不保证真实厚度、两脚分离或可打印性。

正式鞋底实现位于 `sole_repair.py`，只影响底部，保留原有两脚连接；底面仍是平面近似，并非测得的真实鞋底。检查拓扑时使用副本，不在鞋底处理阶段改变全身朝向。随后独立的外观阶段根据外部可见面判断是否需要修正整体朝向。

程序不会监视文件夹后台持续运行；每次数据复制完成后运行一次命令即可。回归后，默认不再根据局部噪声估计随意改变重建参数。常规扫描采用 2 mm 体素、12 mm 邻域、64 邻点、depth 9、两轮点云去噪和两轮 Taubin 网格平滑。仅在非常稀疏的扫描（点间距中位数超过 4 mm）保守放大采样与邻域；这条回退尚未在本批以外的数据验证。统计值用于诊断，不能保证最优或恢复缺失细节。

默认关闭鞋底删面和额外双边后处理。如果基础网格因少量非流形边（同一条边连接超过两个三角面）无法统一面朝向，自动在副本上清理冲突小面并保留最大连通表面；删除面数和面积均不得超过原来的 0.1%，且必须通过边、顶点流形和面朝向检查。保留顶点不移动，可能留下小开口，过程记录在 report.json 的 base_topology_repair 中。清理不通过则保留 intermediate，并写入 failure.json，不导出为成功模型。该规则适用于所有输入，不依赖文件名。

对开口模型不依据中心化有向通量自动翻转整体方向。最终外观阶段改用外部射线可见面的朝向判断；关闭外观处理时保留之前的朝向习惯。这不等于保证任意表面朝向正确或模型可打印。已有差结果不覆盖，代码更新后缓存自动失效，重新运行编号即可。

## 自动和独立处理亮暗与黑点

日常只需运行 `python run.py 1`，会在颜色转移、鞋底处理之后自动修正法线和少量颜色黑点，再导出到同一次 `outputs/models/输入名/时间/`。报告的 appearance 字段分别记录法线和颜色处理结果，模式也参与缓存校验；不需额外执行下面的命令。外观处理不移动顶点，不改变三角面的连接关系；出现处理错误时警告并保留处理前模型，报告记录回退原因。

如需对已有模型单独处理、不重新重建，可以运行：

```powershell
python mesh_appearance.py 1
```

数字代表该编号最新完成的模型，不重新执行点云重建。省略数字处理最近完成的模型；也可直接写网格 PLY 路径。`--all` 处理每个编号的最新模型。若 run.py 已自动处理过，通常无需重复运行本脚本，重复颜色修补可能进一步改变边缘黑点。

默认同时执行两步：先统一相邻三角面的朝向，再从模型外部六个方向发射射线，按每个连通表面的可见面方向判断是否整体翻面；只有至少 50 个可靠命中、且方向票数达到 90% 时才作整体判断，不依赖开口网格的有向体积。判断不明确则保留方向并在报告记录。非流形表面无法统一朝向时不强行翻面。

颜色只修补与邻近表面反差明显的小黑块，用网格连接的邻域边界颜色插值，不跨到空间中挨着的其他肢体。默认最大黑块尺寸 12 mm、最多 120 个顶点，保留大块深色区域；按站立人体比例保护顶部 20% 和底部 8%，减少眼睛、头发和鞋子的误改。比例分区不是人体语义识别，坐姿、倾斜或倒置数据需要指定方向或另外检查。真实的小黑花纹仍可能被当作异常，颜色填补也不是真实颜色测量。

常用选项：

- `--normals-only`：只修正朝向，原始颜色保持不变。
- `--colors-only`：只修补颜色，保留原有三角面朝向和法线。
- `--patch-mm 8`：只处理更小的黑块，比默认 12 mm 保守。
- `--dark-threshold 0.08`：降低暗点亮度阈值，比默认 0.10 保守。
- `--up-axis x`、`--up-sign -1`：指定人体竖直轴和朝上方向。默认明显最长轴、正向朝上；方向不明确时跳过身体颜色修补。
- `--color-region all`：不使用身体比例保护，允许处理整个表面，需特别检查面部和正常黑色图案。
- `--unit m`：网格坐标为米时使用，默认毫米；坐标和单位保持原样。

以上精细参数用于独立脚本。run.py 默认使用 12 mm、亮度 0.10 和身体比例保护；其 `--shoe-axis` 和 `--up-sign` 同时提供给颜色处理用于人体比例分区，即使关闭鞋底修复也可指定方向。run.py 输入单位可为米或毫米，但内部传给外观处理的最终网格始终是毫米。

独立脚本输出到 `outputs/appearance/模型名/本次时间/`，包含外观处理版 PLY、OBJ 和 report.json。每次另建目录，不覆盖输入；顶点位置、三角面连接关系不变，不进行几何平滑，也不整体提高曝光。法线朝向改变后，凹凸受光会变化，不能据此判断几何细节新增或丢失。报告分别记录翻面判断、修补黑块和顶点数量。

## 鞋底为什么变厚以及现在怎么处理

在 export_00003 的既有结果中，网格最低处比主体原始观测向下多延伸约 82 mm。这是明确的外扩证据，不是鞋底真实厚度的测量。

仅在显式开启 --sole-axis auto/x/y/z 时，流程在 Poisson 重建后检查原始保留观测最低点附近 120 mm 的脚部范围。距观测超过自动阈值（至少 6 mm，或 3 倍体素尺寸）的网格顶点会被删除，避免没有观测支持的底面扩张成厚块。该阈值限制观测偏离，不是指定鞋底厚度。

显式选择 auto 后，只有在某个坐标轴明显更长时才将其视为竖直轴，并假设正向朝上。这不是语义姿态识别；坐姿、横放、倒置或抬脚时请显式指定轴及方向，或者关闭。扫描本身若带有地面、厚底或缺失的脚部信息，该规则也不保证修正真实形状。

删除虚构表面后可能出现底部开口，不会为了封闭而重新填入假鞋底。若用于打印，需要另外检查和修补孔洞；默认仍跳过昂贵的完整自交检查，不能据此声明可打印。

## 统一输出位置

```text
data/                                    原始 PLY，不修改
outputs/
  models/输入名/本次时间/
    输入名_mesh.ply                       最终模型
    输入名_mesh.obj                       同一模型的 OBJ
    textured/face_uv.obj                 可选照片贴图版，MTL 和 PNG 放在同一目录
    report.json                           自动参数和质量检查
    body_parts.json                       分割部位的位置、顶点编号及来源网格校验信息
    hand_centerlines.json                 人体自动处理生成的中心线、评分与来源校验
    intermediate/                        本次后处理前的基础网格及报告
  manual/输入名/本次时间/                 手动运行 reconstruct_human.py 的默认输出
  conversions/输入名/                     单独运行 ply_to_obj.py 的默认输出
  appearance/模型名/本次时间/             独立法线和颜色处理结果
  comparisons/                           历史汇总对比图
  history/scan/                          旧手动重建，保留用于参考
```

旧 auto 目录迁入 models，旧 scan 迁入 history/scan，原文件保留；旧模型中间目录可能仍名为 base，不代表新运行仍采用该命名。历史报告内的绝对路径属于生成当时的记录，迁移后不一定仍有效。新代码改变后缓存会失效，重新运行不会覆盖历史模型。

## 保留脚本分别做什么

每个脚本开头也有同样的简短说明与参数示例。

- run.py：日常自动入口，通常只需运行它。
- reconstruct_human.py：分步重建，可手动设采样、去噪和重建参数。
- surface_detail.py：内部几何工具，不单独执行。
- mesh_refine.py：独立网格后处理工具；run.py 默认不额外过滤，只有 --refine 才开启。
- ply_to_obj.py：独立格式转换；run.py 已同时输出 OBJ。
- tools/face_uv.py：用配套照片生成可选的脸颈 UV 贴图，由 run.py 调用。
- mesh_appearance.py：外观处理模块，run.py 默认调用；也可独立处理已有模型。
- body_parts.py：run.py 默认调用的人体部位位置模块，生成/读取 body_parts.json，不优化几何。
- hand_centerlines.py：共享的掌部约束、多尺度中心线和三维观测检查，不单独修改模型。
- skeleton_hand.py：默认统一手部处理及兼容实验入口，按采样误差和质量门决定是否调整。
- hand_density_constraints.py：密度阈值、低覆盖虚接过滤和双侧观测厚度约束；自动模式保护原有边界数量。
- palm_volume.py：默认掌部整体限厚，包含椭圆截面、腕部参考、平滑过渡、指尖保护和质量回退，不单独运行。
- palm_pipeline.py：已撤回默认的掌面实验模块，仅 --hand-refine 显式调用。
- hand_pipeline.py：共用几何工具和历史整手平滑实现，整手平滑已撤回默认。
- finger_restore.py：历史指部回补工具；实验掌面模块仅借用其分区掩码排除指部，不执行回补变形。
- requirements.txt：环境依赖清单，不是执行脚本。

tools/restore_segmentation_stage.py 可复用中间网格恢复仅识别阶段（--all 或 --scan 3），日常无需重复运行。旧的独立手部试验、整手平滑和指部回补入口已清理；日常只运行 run.py。hand_pipeline.py 和 finger_restore.py 仍提供可选掌面实验模块依赖的几何函数、指部分区掩码，因此保留，不作为日常命令入口。

## 需要手动调整时

示例均在项目根目录执行：

```powershell
python reconstruct_human.py data/export_00003.ply --preset scan --no-vis --skip-self-intersections
```

常用参数：

- --preset scan：主体筛选、稳健法线及局部平面去噪。
- --voxel 0.002：2 mm 体素，参数单位为米。
- --depth 9：Poisson 深度，提高不等于真实细节增加。
- --sole-guard auto：显式开启脚部约束，可改 x、y、z；默认 off。
- --sole-margin-mm 6：脚部附近距观测最大容许距离，单位毫米。
- --up-sign -1：竖直轴负向朝上。
- --out 路径：显式指定目录，省略即采用上述统一默认目录。
- --no-vis：不弹交互窗口；去掉后可查看模型。
- --skip-self-intersections：跳过完整自交检测，仅适合快速比较。
- --save-intermediates：额外输出 processed 点云及 highres 网格。
- --help：完整参数。

独立后处理和转换示例：

```powershell
python mesh_refine.py outputs/models/输入名/时间/输入名_mesh.ply --source data/export_00003.ply --out outputs/manual/refine/本次名称 --max-move-mm 1
python ply_to_obj.py outputs/models/输入名/时间/输入名_mesh.ply
```

将“输入名”和“时间”替换成实际目录。后处理的 --out 必须显式给出独立目录。转换默认输出至 conversions，--out 可以覆盖默认位置，--overwrite 才允许覆盖已有 OBJ。

## 文件含义与限制

mesh 是三角网格；processed 是去噪点云，不是网格；highres 是面数简化前的网格，不等于新增的高精度观测。独立后处理的支撑着色图用于显示局部观测不足，颜色不是精度概率。

普通 `输入名_mesh.obj` 使用顶点颜色，显示取决于查看软件。有 `textured/face_uv.obj` 时可以用它查看脸颈照片纹理。仅有点的 PLY 需先重建，转换工具 `--points-only` 只输出点。

只有显式开启 --refine 的额外网格后处理才会限制顶点移动，并检查同一批原始观测到网格的距离。偏离增加过多则退回基础网格。原始观测也不是无噪声真值，不能用该检查宣称几何精度提升。
