# 点云重建与保守网格去噪

保留方案：传统点云清理 → 稳健局部平面法线 → Poisson 重建 → 限定位移的双边面法线去噪。不使用深度学习，也不凭空补造五官。

## 目录

```text
data/                      三份原始采集 PLY，禁止当作实验产物删除
reconstruct_human.py       点云清理、法线、Poisson、颜色和质量检查
surface_detail.py          主体连通分量、稳健平面拟合和有界点云去噪
mesh_refine.py             有界双边面法线过滤与网格顶点更新
requirements.txt           运行依赖
tests/                     当前方案的 13 项回归测试
docs/使用说明.md            统一说明
outputs/comparisons/       保留的历史汇总对比图
```

历史模型、逐项预览、NPZ、报告、参数搜索和头部专项试验脚本已经清理；历史对比图仅用于回顾，不再对应磁盘上的完整实验模型。重新生成当前方案按以下命令执行。

## 在 VS Code 终端运行

在 VS Code 打开本项目文件夹，选择你已有的 Python 虚拟环境，并在终端激活它。不需要创建新环境。以下均为 PowerShell 单行命令，从项目根目录执行。

```powershell
python -c "import sys; print(sys.executable)"
```

确认输出为自己的环境。之前测试使用的是 `dachuang` 环境，但并不要求固定安装路径。仅在缺少依赖时执行：

```powershell
python -m pip install -r .\requirements.txt
```

### 第一步：原始点云生成完整网格

```powershell
python .\reconstruct_human.py .\data\export_00001.ply --preset scan --out .\outputs\scan --no-vis --skip-self-intersections
python .\reconstruct_human.py .\data\export_00002.ply --preset scan --out .\outputs\scan --no-vis --skip-self-intersections
```

`export_00000.ply` 同样在 `data`，替换输入文件名即可。不指定输入时默认读取它；本批新数据建议显式指定 `--preset scan`。

`scan` 的关键参数为 2 mm 体素、Poisson depth 9、不做面数简化、12 mm 稳健法线邻域、两轮局部平面点云去噪（累计位移上限 1 mm）和两轮网格平滑。先在粗代理点云上选最大连通主体，减少背景参与重建；它假设单个人体主体，多主体或断开的有效部件可用 `--point-components all` 保留。

程序内部长度单位为米，当前输入默认为毫米，输出默认跟随输入。更换单位的数据必须设置 `--input-unit`。不要把 `--voxel` / `--normal-radius` 的米和 `--max-move-mm` 等毫米参数混淆。

`--skip-self-intersections` 只跳过昂贵的网格自交检查，其他检查照常进行，适合快速比较；它不代表模型没有自交。需要完整检查时去掉它。`--threads 4` 可限制 CPU 并行线程。

去掉 `--no-vis` 会打开交互窗口：1 网格、2 原点云、3 叠加、W 线框、C 颜色/灰色、N 平滑/平面法线显示。

### 第二步：保守的上部网格优化

第一步完成后执行：

```powershell
python .\mesh_refine.py .\outputs\scan\export_00001_mesh.ply --source .\data\export_00001.ply --out .\outputs\refined_1 --max-move-mm 1 --active-min-x-mm 837.186928
python .\mesh_refine.py .\outputs\scan\export_00002_mesh.ply --source .\data\export_00002.ply --out .\outputs\refined_2 --max-move-mm 1 --active-min-x-mm 888.194920
```

这两个 X 阈值只针对当前两份扫描的坐标系，竖直方向为 X。不是语义人脸分割，第二份同高度的抬起手臂也会处理；不要直接套用于其他扫描。阈值处有 30 mm 渐变带，完全非活动区域的位置与原有颜色保留。不指定 `--active-min-x-mm` 则处理全网格。

方法在共享顶点的三角面邻域做双边法线过滤，再更新顶点，不跨空间近邻跳到另一层表面。保持面连接，冻结边界和非流形边顶点，限制相对输入网格的累计位移，并做局部面翻转保护。默认法线过滤 5 轮、顶点更新 12 轮；增加次数不等于恢复更多真实细节。

第一步同名产物已存在时需要显式加 `--overwrite` 才能覆盖。第二步重复使用相同 `--out` 会覆盖该目录内工具生成的同名结果，想保留不同候选请换输出目录。两步均不修改原始输入。

## 输出文件分别是什么

- `*_mesh.ply`：第一步最终三角网格，主要查看对象。
- `*_processed.ply`：清理、下采样、去噪并估计法线后的点云，不是网格。
- `*_highres.ply`：简化前的网格，不是新增的高精度原始观测；关闭简化时可能与最终网格接近。
- `*_rejected_components.ply`：被主体筛选排除的点，用于检查有无误删。
- `*_report.json`：第一步参数和质量检查记录。
- `refined_mesh.ply`：第二步保守优化后的完整网格。
- `before_support.ply` / `after_support.ply`：去噪前后的观测支撑着色，不是正常 RGB 模型。
- `before_support.npz` / `after_support.npz`、`report.json`：第二步支撑统计、参数及检查结果。

第一步默认不输出上述中间 PLY，需要时加 `--save-intermediates`。所有新产物请继续放到 `outputs` 的子目录，和原始 `data` 分开。

支撑图在 8 mm 邻域统计原始观测：不足 6 点或最近点超过 10 mm 为红色；其他点中不足 12 点，或沿法线方向的稳健离散度超过 1.5 mm 为黄色；其余为绿色。这是可检查的经验诊断规则，不是准确率或设备标定置信度，曲率、遮挡也影响颜色。

## 当前效果及限制

设备只提供合成 PLY，没有逐帧深度、相机位姿或原始采集项目，因此不能在这里重新做逐帧配准，也无法保证恢复原始数据中已缺失的五官结构。

已保留的轻度上部去噪方案累计位移不超过 1 mm。历史测试中，头部顶点移动 P95 分别约 0.574 / 0.701 mm；相对原始头部观测的 P95 距离从 6.321 → 6.414 mm、7.647 → 7.912 mm。表面更平顺，但观测拟合并没有变得更准确，不能把平滑当作精度提升。

历史两个完整候选的边界边仍有 32 / 30 条，第二份仍有 13 条非流形边。这套后处理保持连接关系，不自动修复这些拓扑问题；局部面翻转保护也不等于完整自交检查。当前主要用于外观比较，不应直接宣称可打印或完全水密。

对比图归档：

- `outputs/comparisons/scan/`：新扫描不同重建配置的头部对比。
- `outputs/comparisons/head/export_0000x/`：头部专项正侧面、筛选结果与截面对比，含已放弃的实验。
- `outputs/comparisons/refine/export_0000x/`：完整模型上部限定过滤与局部强弱过滤对比。
- `outputs/comparisons/denoise/`：早期点云去噪对比。

当前方案主要参考 [第一份完整网格对比](../outputs/comparisons/refine/export_00001/full_head_comparison.png) 与 [第二份完整网格对比](../outputs/comparisons/refine/export_00002/full_head_comparison.png)。图中的历史候选标签不是仍然可执行的脚本或路径。
